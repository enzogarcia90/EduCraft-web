Datos Del Producto

Lo importante para entender EduCraft de un vistazo

La web puede hablar de lo que EduCraft hace y hacia dónde va: aulas, perfiles, políticas, paneles privados, avisos, sesiones, acciones educativas y contenido científico. Lo que no debe publicar son datos internos, claves, configuraciones privadas ni detalles sensibles del producto.

Cliente EduCraft

Experiencia web personalizada para EduCraft, basada en tecnología compatible con Minecraft 1.8 y adaptada a centros educativos.

Identidad educativa

Usuarios, roles, permisos e instituciones para separar alumnos, docentes y administración.

Política remota

Configuración de experiencia por centro: mundos locales, recursos, skins y comportamiento permitido.

Seguridad gradual

Señales de integridad y telemetría para detectar anomalías, con enfoque progresivo y verificable.
