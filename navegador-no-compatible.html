Navegador no compatible

El cliente de EduCraft requiere un navegador basado en Chromium para ofrecer la experiencia web prevista.

Prueba cualquiera de estos navegadores compatibles y vuelve a abrir el cliente.

Google Chrome Opera Brave

¿Usas Firefox u otro navegador?

Firefox y Safari no se bloquean para navegar por la web pública, pero no son compatibles con el cliente web de EduCraft. Puedes continuar consultando la plataforma desde este navegador.
