Centros educativos

Una plataforma educativa para organizar experiencias de aula

EduCraft está pensada para colegios e institutos que quieren trabajar programación, STEM y pensamiento computacional con entornos compatibles con Minecraft, sin separar la actividad de la organización docente.

El aula necesita más que un mundo

El uso educativo requiere acceso organizado, normas, actividades comprensibles y seguimiento. EduCraft combina una experiencia web para el alumnado con una zona privada por roles para que cada participante acceda a las herramientas que le corresponden.

La plataforma se encuentra en evolución. Las demostraciones y pilotos se acuerdan con el centro, en lugar de asumir una configuración o un resultado idéntico para todos.

Roles para una actividad organizada

El producto diferencia las necesidades de alumnado, profesorado, centro y equipo TIC. Esto permite evitar que la experiencia de juego sustituya las responsabilidades pedagógicas y operativas del centro.

Profesorado

Prepara actividades, acompaña la sesión y revisa entregas y rúbricas con su propio criterio.

Alumnado

Accede a la actividad asignada y trabaja con objetivos, avisos y contexto educativo.

Centro educativo

Organiza usuarios, roles y la información necesaria para sus sesiones.

Equipo TIC

Dispone de una superficie privada para la operación y el seguimiento técnico autorizado.

¿EduCraft funciona desde el navegador?

EduCraft cuenta con un cliente web para acceder desde el navegador. La disponibilidad y el alcance de cada experiencia dependen de la cuenta autorizada, el centro y la fase de despliegue acordada.

Si buscas una propuesta para tu centro, consulta la plataforma, explora la educación con Minecraft o solicita una demostración.
