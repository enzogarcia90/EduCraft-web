Panel docente en preparación

Esta zona está reservada para el futuro dashboard de EduCraft: sesiones, aulas, actividad, avisos y señales educativas. De momento es una vista pública de estado, sin datos privados.

En desarrollo El dashboard todavía no muestra datos reales. Cuando esté conectado, la información vendrá de la API privada y requerirá permisos de centro.

Gestión futura de avisos y mensajes visibles para alumnos antes de entrar al mundo.
