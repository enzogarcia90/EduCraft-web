Plataforma

Una plataforma para preparar, dirigir y revisar cada sesión

EduCraft conecta acceso web, control docente, seguimiento, revisión de entregas, servidores de aula y contenido STEM en un flujo diseñado para centros educativos.

MVP disponible para pilotos El cliente web está en evolución y disponible para demostraciones y pruebas acompañadas. El alcance de cada piloto se define previamente con el centro.

Experiencia Del Alumno

Pensamiento Computacional

Programación por bloques y lógica algorítmica en el mundo

EduCraft incorpora herramientas para enseñar programación de forma práctica y visual. Los estudiantes escriben lógica de programación que se ejecuta directamente en el entorno tridimensional, observando el resultado de sus algoritmos en tiempo real.

Programación visual

Lógica de bloques intuitiva para aprender secuenciación, condicionales, bucles y variables sin barreras de sintaxis.

Automatización espacial

Creación de agentes constructores, generación procedural de patrones geométricos y resolución de laberintos.

Retos y misiones

Plantillas didácticas de informática listas para activar en 1 clic con enunciados, objetivos y evaluación guiada.

De bloques a código

Puente didáctico hacia lenguajes estándar (Python y JavaScript) conforme los alumnos desarrollan mayor competencia técnica.

Dashboards

Paneles claros para centro, TIC y profesorado

EduCraft incorpora una zona privada para organizar aulas, revisar actividad educativa, publicar avisos y preparar acciones de clase sin exponer datos internos ni detalles técnicos del servicio.

Centro

Instituciones, usuarios, horarios, políticas y visión general desde un acceso basado en roles.

Profesorado

Preparación de actividades, control en vivo, seguimiento, rúbricas e integridad de entregas en un mismo flujo.

Equipo TIC

Estado de servidores Paper/Docker, consolas legibles, telemetría y visor 3D WebGL 2 en tiempo real.

Comunidad

Verificación de cuentas con Discord y avisos controlados para conectar el aula con la comunicación del centro.

Contenido Científico

118 elementos químicos para aprender de forma visual

EduCraft ya tiene una base visual para representar la tabla periódica como bloques dentro del cliente. La intención no es decorar inventarios, sino convertir cada elemento en una puerta a conceptos, retos, misiones y actividades guiadas.

Química visual

Elementos convertidos en objetos reconocibles dentro del mundo para trabajar memoria, clasificación y propiedades.

Retos de laboratorio

Misiones en las que construir moléculas, combinar reactivos, observar reacciones y explicar procesos científicos.

Aprendizaje espacial

Representación de conceptos abstractos como estructuras cristalinas, familias químicas y enlaces moleculares.

Evaluación formativa

Seguimiento continuo mediante libros de laboratorio entregados, preguntas integradas y rúbricas del docente.
