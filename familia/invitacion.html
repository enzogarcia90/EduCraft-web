¿Por qué recibes este mensaje?

EduCraft utiliza Minecraft Java Edition en actividades organizadas por centros educativos. Esta página permite revisar la solicitud familiar y, cuando el servicio esté habilitado, iniciar la vinculación oficial con Microsoft.

Nunca introduzcas tu contraseña de Microsoft en EduCraft. La autenticación se realiza únicamente en la página oficial de Microsoft. Abrir este enlace no demuestra por sí solo la tutela legal ni concede acceso al alumno.

La vinculación Microsoft se habilitará cuando el registro oficial OAuth y la verificación de Minecraft Java estén disponibles.
